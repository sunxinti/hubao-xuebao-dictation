## 为什么做这个小工具

用 Mac 远程操作另一台电脑时，我们只是想把一句话变成文字，再顺手粘贴过去。试过一些软件后，麦克风、远程桌面焦点和窗口切换仍让这件小事变得麻烦。

于是，我们让虎宝和雪宝待在桌面一角：点一下，开口说话；说完，文字就在旁边。识别在 Mac 本机完成，复制后可粘贴到需要的地方。

我们把这个独立小工具的源码公开，希望也能帮到有相似需要的人。非商业用途可免费使用、研究、修改和分享，具体以许可证为准。

## 它能做什么

- **点一下就听写**：点击小狗或按 `Option + 空格` 开始，再点一次结束。
- **说完自动结束**：默认停顿 1.8 秒后转写，可调整为 1.2 / 1.8 / 2.5 / 3.5 秒。
- **旁边看结果**：文字卡片支持复制；也可关闭文字框，保留自动复制。
- **适合远程桌面场景**：悬浮小狗与卡片使用不主动抢焦点的窗口，支持 macOS 多桌面与全屏空间。
- **完全本地识别**：使用 Qwen3-ASR-0.6B 的社区 MLX 量化版本，不需要购买云端转写服务。
- **小狗大小可调**：70%、100%、125%，可拖动到舒服的位置。
- **可选语音唤醒**：支持“虎宝雪宝”“虎宝虎宝”“雪宝雪宝”“你好虎宝”“你好雪宝”。文字匹配已有测试，真实环境的唤醒率仍需试用确认。

这是听写工具，不是远程控制软件。它不负责连接另一台电脑，也不自动执行你说出的命令。

## 下载与第一次使用

请查看 [GitHub Releases](https://github.com/sunxinti/hubao-xuebao-dictation/releases)。可用的完整应用包及 SHA-256 会作为 Release 附件提供；如果尚无附件，请按下方构建说明从源码准备。不要把 GitHub 自动生成的 Source code ZIP 当作完整应用。

完整应用包的使用流程：

1. 下载适配 Apple Silicon 的完整应用包，解压后打开应用。
2. 等待本地模型就绪。首次录音时，在 macOS 系统提示中允许麦克风访问。
3. 点击小狗或按 `Option + 空格`，说出要转成文字的内容。
4. 说完停顿，或再次点击小狗。转写结果默认自动复制。
5. 在目标文本框中粘贴；右键小狗可以调整显示、大小、设置或退出。

当前构建采用本机临时签名，尚未完成 Apple Developer 正式签名与公证。macOS 可能阻止直接打开互联网下载的应用；请核对来源和校验值。我们不建议关闭 Gatekeeper；也可按构建文档在自己的 Mac 上从源码构建。

## 配合 ToDesk 等远程桌面

1. 在 **Mac 本机**运行听写工具，并打开远程桌面。
2. 点击悬浮小狗，说话后等待本地转写完成。
3. 文字进入 **Mac 剪贴板**。
4. 将焦点放到远程电脑的输入框，使用远程桌面支持的粘贴方式。

远程粘贴依赖 ToDesk 等软件的剪贴板同步设置。若粘贴失败，先在 Mac 本地文本框尝试，确认听写已完成，再检查远程剪贴板。不能保证所有远程软件、版本和多显示器组合都兼容。

## 隐私

识别无需 API Key 或账号。当前实现通过父子进程管道把录音交给本地模型，没有云端识别后备线路；界面阻止 HTTP/HTTPS/WebSocket 请求，推理进程启用离线设置及 Python 网络审计限制。

应用代码不主动保存录音或听写历史；当前文字保留在界面内存中。自动复制会写入系统剪贴板，剪贴板管理器、系统同步或远程桌面可能根据你自己的设置处理这些文字。

开启语音唤醒后，应用会持续使用麦克风并在本机分段识别声音，带来额外耗电。锁屏或睡眠会暂停唤醒。完整说明见 [PRIVACY.md](PRIVACY.md)。这些实现检查不等同于独立安全认证。

## 常见问题

**需要联网或者付费模型账号吗？** 下载安装文件或开发依赖时需要网络；完整模型与运行组件准备好后，听写不需要联网或云服务账号。

**为什么停下来想一想，听写就结束了？** 结束判断依据声音与停顿，不理解语义是否完整。可将停顿调到 3.5 秒，或分段听写。每段最长 120 秒。

**为什么没有文字？** 确认麦克风权限、本地模型就绪状态和输入设备。约 8 秒没有有效声音会自动取消；极短声音可能被当作误触。模型识别也可能有错误，重要内容请核对。

**点击小狗会切回主窗口吗？** 日常听写和复制使用不主动激活的悬浮窗口；详细设置由你主动打开。不同远程软件的焦点表现仍需实际验证。

**这是千问聊天助手吗？** 不是。当前只做语音转文字，没有聊天回答、自动润色或命令执行。

## 开发与构建

构建使用 Electron 45.0.0、Python 3.12.14、mlx-qwen3-asr 0.4.4、MLX 0.32.4。Node 22 或更新版本可运行源码测试：

```sh
node --test tests/*.test.cjs
```

2026-10-28 本地复核：12 项测试通过，覆盖录音数据、脚本语法、卡片复制、窗口布局与不主动抢焦点的调用行为。这些测试不替代真实麦克风、Metal 推理和远程桌面验收。

使用 Python 3.12 或更新版本，准备固定版本运行组件与模型，再打包：

```sh
python3 scripts/prepare_runtime.py
python3 scripts/package.py
```

模型固定来源为 `moona3k/mlx-qwen3-asr-0.6b-4bit`，revision 为 `4c59c533f95c84afb796655e814709034f826f04`。不把个人电脑的 Python 目录、缓存或配置直接纳入源码仓库。

准备脚本校验 Python、Electron、模型和 Python wheel 的 SHA-256，拒绝复用来源不明的运行环境。详细前置条件、目录和故障处理见 [构建说明](docs/BUILD.md)。产物在 `dist/虎宝雪宝听写.app`。
